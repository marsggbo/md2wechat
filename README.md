# ⚠️ 此插件已改名升级为 Markdown2Anything

> **md2wechat 已升级为 [Markdown2Anything](https://github.com/marsggbo/markdown2anything)**，请安装新版插件。

## 快速迁移

**VS Code 扩展市场**：搜索 `Markdown2Anything` 或 `marsggbo.markdown2anything` 安装新版。

```bash
# 卸载旧版
code --uninstall-extension marsggbo.md2wechat

# 安装新版
code --install-extension marsggbo.markdown2anything
```

## 新版有什么变化？

- ✅ **新增目录（TOC）面板** — 预览时一键展开文章大纲，点击标题跳转，仅预览用不影响导出
- ✅ 自定义工具栏图标，更容易辨认
- ✅ 插件改名为 `markdown2anything`，定位更准确（不只是微信，也支持知乎、小红书）
- ✅ 所有原有功能完整保留：LaTeX 公式、10 套主题、微信/知乎/小红书复制、截图导出、上传草稿箱
